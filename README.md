# 🕌 المنصة الرسمية لفضيلة الشيخ علاء إبراهيم (Sheikh Alaa Ibrahim)

المنصة الرقمية والمكتبة المرئية العلمية الرسمية لفضيلة **الشيخ علاء إبراهيم** (باحث وداعية إسلامي أزهري). تهدف المنصة إلى نشر الفكر الأزهري الوسطي المستنير، وتيسير الوصول إلى الدروس والمحاضرات والبودكاست الفكري وتأصيل قضايا العصر.

---

## ✨ المميزات الرئيسية (Key Features)

- **🏛️ تصميم أزهري إسلامي فاخر:** واجهة عصرية متطورة تعتمد على ألوان رصينة (كحلي ملكي وذهبي إسلامي) مع دعم كامل للوضعين الداكن والفاتح (Dark / Light Mode).
- **📂 مكتبة مرئية مصنفة موضوعياً:**
  - 🎙️ **بودكاست وحوارات فكرية متعمقة:** لقاءات وحوارات فكرية مطولة عالية الدقة (`16:9`).
  - 🧕 **فقه وقضايا المرأة والأسرة المسلمة:** معالجة علمية لأحكام الحجاب، النقاب، الزواج، والحقوق الأسرية.
  - 🕌 **أحكام الصلاة والعبادات والطهارة:** فقه الصلاة والسنن، ستر العورة، والوضوء.
  - ⚖️ **تأصيل فكري وقضايا وشبهات معاصرة:** مناقشة القضايا الفكرية الحديثة وتفنيد الشبهات وتصحيح المفاهيم.
  - 💡 **قبسات وشورتس دعوية موجزة:** مقاطع دعوية وتربوية سريعة وهادفة.
- **📱 مشغل فيديو متكيف تلقائياً (Adaptive Video Player):** دعم المقاطع الطولية (`9:16`) للشورتس والفيديوهات العريضة (`16:9`) مع إمكانية التبديل اليدوي السريع.
- **⏱️ مواقيت الصلاة الحية والتنبيه الذكي:** جلب دقيق لمواقيت الصلاة في القاهرة مع تنبيه ذكي مؤقت يختفي تلقائياً بشريط عد تنازلي.
- **📿 شريط الأذكار المأثورة:** كبسولة أذكار متجددة بشفافية أنيقة تظهر وتختفي دون مقاطعة التصفح.
- **📜 السيرة والملف العلمي:** صفحة شاملة للمسيرة العلمية والإجازات والشهادات والمنهج الأزهري الوسطي.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** CSS3 Design System + Glassmorphism + Responsive Layouts
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **API:** Aladhan Prayer Times API via [Axios](https://axios-http.com/)
- **Routing:** [React Router v7](https://reactrouter.com/)

## 🚀 التشغيل والتثبيت محلياً (Getting Started)

1. **استنساخ المستودع (Clone):**
   ```bash
   git clone https://github.com/ELiSiSi/sheikh-alaa-ibrahim.git
   cd sheikh-alaa-ibrahim
   ```

2. **تثبيت الحزم (Install Dependencies):**
   ```bash
   npm install
   # أو
   pnpm install
   ```

3. **تشغيل خادم التطوير (Run Dev Server):**
   ```bash
   npm run dev
   # أو
   pnpm dev
   ```

4. **بناء النسخة الإنتاجية (Build for Production):**
   ```bash
   npm run build
   ```
